# Aprendizado-Python
Aprendendo Python com PNAAT

Módulos essenciais:

math: Fornece acesso a funções matemáticas. Exemplo: math.pow(base, exp) para exponenciação, math.log(x) para logaritmos em análises de dados.
random: Permite gerar números pseudoaleatórios. Exemplo: random.uniform(a, b) para gerar um valor de sensor simulado entre a e b.
datetime: Fornece classes para manipulação de datas e horas. Exemplo: datetime.now() para obter o timestamp atual antes de salvar uma leitura de sensor em um arquivo.
